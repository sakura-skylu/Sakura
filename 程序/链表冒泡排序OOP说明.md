# 链表冒泡排序OOP实现

## 概述
这是一个完整的面向对象C++程序，实现了基于模板的单链表数据结构和冒泡排序算法，包含丰富的运算符重载和文件I/O功能。

## 核心特性

### 1. 面向对象设计
- **Node<T> 类**: 模板化的链表节点类，封装数据和指针
- **LinkedList<T> 类**: 模板化的链表类，提供完整的链表操作接口

### 2. 运算符重载
**Node类运算符**:
- `operator<` - 小于比较
- `operator>` - 大于比较
- `operator==` - 等于比较
- `operator!=` - 不等于比较
- `operator<=` - 小于等于比较
- `operator>=` - 大于等于比较
- `operator<<` - 输出流操作符

**LinkedList类运算符**:
- `operator=` - 赋值运算符（深拷贝）
- `operator<<` - 输出流操作符
- `operator>>` - 输入流操作符

### 3. 核心功能
- **append()** - 在链表末尾添加元素
- **bubbleSort()** - 冒泡排序算法实现
- **display()** - 显示链表内容
- **clear()** - 清空链表并释放内存
- **getSize()** - 获取链表大小
- **isEmpty()** - 检查链表是否为空

### 4. 文件I/O操作
- **readFromFile()** - 从文件读取数据
- **writeToFile()** - 将数据写入文件

### 5. 内存管理
- 析构函数自动释放所有节点内存
- 拷贝构造函数实现深拷贝
- 赋值运算符实现深拷贝

### 编译命令

## 使用示例

程序包含四个演示模块：

### 1. 基础操作演示
```cpp
LinkedList<int> list;
list.append(64);
list.append(34);
list.append(25);
list.bubbleSort();
list.display();
```

### 2. 文件操作演示
```cpp
LinkedList<int> list;
list.readFromFile("input.txt");
list.bubbleSort();
list.writeToFile("output.txt");
```

### 3. 运算符重载演示
```cpp
LinkedList<int> list1;
std::cout << list1 << std::endl;  // 使用<<输出
LinkedList<int> list2 = list1;     // 拷贝构造
```

### 4. 泛型支持演示
```cpp
LinkedList<double> list;
list.append(3.14);
list.append(2.71);
list.bubbleSort();
```

## 冒泡排序算法

实现了优化的冒泡排序算法：
- 通过交换节点数据而非指针来实现排序
- 使用lastSorted标记减少不必要的比较
- 使用swapped标志提前终止已排序的情况

时间复杂度：
- 最好情况：O(n) - 已排序
- 平均情况：O(n²)
- 最坏情况：O(n²)

空间复杂度：O(1)

## 设计原则

1. **封装性**：数据成员私有，通过公有接口访问
2. **模块化**：功能分离，职责明确
3. **可复用性**：模板设计支持多种数据类型
4. **可维护性**：清晰的代码结构和命名
5. **内存安全**：正确的资源管理和内存释放

## 代码规范

- 使用驼峰命名法
- 适当的缩进和格式化
- const正确性
- 友元函数用于运算符重载
- 模板类完整实现在头文件中

## 注意事项

1. 程序使用C++98兼容的NULL而非C++11的nullptr，确保广泛兼容性
2. 使用.c_str()方法确保与旧版编译器兼容
3. 文件操作后正确关闭文件句柄
4. 深拷贝确保对象独立性，避免内存问题
